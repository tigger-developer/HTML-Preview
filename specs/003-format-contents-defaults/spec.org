* Format-specific contents defaults
:PROPERTIES:
:CUSTOM_ID: summary
:END:

- Outcome :: *Markdown defaults to contents on; Org defaults to contents off*.
- Before :: *Both formats defaulted to contents on* through heading level 3.
- After :: *Markdown keeps depth 3*. Explicit TOC settings override either
  format's default across the invocation, including linked documents.
- Changes :: *Resolve the default separately for each document* and update help.
- Unchanged :: *Standalone stays true*, depth remains configurable from 1 to 6,
  and application choices override source TOC metadata.
- Edge cases :: *Empty TOC selects format defaults*. Depth alone leaves Org
  contents off; invalid depth still fails before preview allocation.
- Decisions :: *The operator authorized this bounded change with BYPASS-GATE-7*.
  This document records the result after implementation, not an earlier definition.
- Next step :: *Implementation audit and final verification*, then operator closure.

** AC003.1 - Each format selects its default
:PROPERTIES:
:CUSTOM_ID: ac-003-1
:END:

- Criterion :: With unset/empty TOC, *each Markdown page has contents through
  source level 3 by default; each Org page has no contents navigation*.
  This holds for explicit inputs and linked pages, independently of input order.
  Documents with no eligible headings continue to omit empty navigation.
- Proven by :: [[#rt-003-1][RT003.1 - Per-document defaults]] and
  [[#ot-003-1][OT003.1 - Documentation reconciliation]].

** AC003.2 - Explicit settings retain their meaning
:PROPERTIES:
:CUSTOM_ID: ac-003-2
:END:

- Criterion :: *Explicit TOC 0/1 disables/enables contents for all documents*.
  Depth defaults to 3 and accepts 1 to 6. Depth alone does not enable Org TOC.
  Application defaults/settings override source metadata; invalid settings
  retain status 2 before allocation. *Output remains standalone*.
- Proven by :: [[#rt-003-1][RT003.1 - Per-document defaults]] and
  [[#ot-003-1][OT003.1 - Documentation reconciliation]].

* Edge Cases
:PROPERTIES:
:CUSTOM_ID: edge-cases
:END:

- Mixed graphs :: *Defaults follow each page's format*, including after an Org
  input, rather than adopting the first entry's choice.
- Empty settings :: *Empty TOC is absence of an override*; empty depth uses 3.
- Inactive depth :: *Org stays off when only depth is set*; malformed depth fails.
- Source metadata :: *Source TOC directives cannot replace application choices*.
- Coverage :: [[#rt-003-1][RT003.1 - Per-document defaults]] protects these cases.

* Solution Design
:PROPERTIES:
:CUSTOM_ID: solution-design
:END:

- Configuration :: *Retain whether a nonempty TOC override was supplied* beside
  its validated Boolean value. Keep the existing depth validation/default.
- Rendering :: *Select the effective TOC locally for each document*. Use the
  same case-insensitive Org detection as the Pandoc input format. Org chooses
  false only when no override exists; never mutate invocation configuration.
- Converter :: *Pass the effective Boolean and depth explicitly to Pandoc*.
  Standalone defaults, templates, transport and browser controls are unchanged.
- Security :: *No trust or access boundary changes*. Source metadata remains
  subordinate to application settings; no new file, network or execution path.
- Other qualities :: *No platform-specific branch, persistent state or added
  dependency*. The extra per-document choice is constant work. Existing
  navigation accessibility and install/rollback mechanisms remain applicable.
