* Agreed increment: Org footnote section
** AC013.1 - First footnote gets a configurable section :ac:
:PROPERTIES:
:CUSTOM_ID: ac-013-1
:END:
- Default :: When creating the *first footnote in an Org document*, append a
  top-level =* Footnotes & Annotations= heading and a *blank line* before the
  first definition.
- Configuration :: =annotations.section_title= defaults to
  =Footnotes & Annotations=. A custom string changes the title; an *empty string
  disables* automatic heading creation.
- Repetition :: Later footnotes reuse the section without duplicating its heading.
- Existing documents :: Preserve existing footnote organization and headings.
- Boundary :: This increment concerns *Org source organization*. Markdown
  behaviour and the block-end insertion policy remain unchanged.

* Agreed correction: reachable annotation blocks
** AC013.2 - Reachable block annotation targets :ac:
:PROPERTIES:
:CUSTOM_ID: ac-013-2
:END:
- Wrapped descriptions :: Multiline inline verbatim/code must not prevent a
  rendered description paragraph from being an annotation target. Its label
  should reach the same verified description boundary.
- Indented containers :: Quotes inside list descriptions remain whole-block
  targets. Save the reference *after the closing delimiter*, preserving list
  indentation and surrounding items; subsequent references reuse that paragraph.
- Preservation :: Keep source/HTML correspondence checks and rejection of
  unverified targets. No private source content enters tracked fixtures.
- Baseline :: Restores the existing whole-block interaction described in
  [[file:../011-conversion-performance/spec.org][W011 - Native Org preview compatibility]].
