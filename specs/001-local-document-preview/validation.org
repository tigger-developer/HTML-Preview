** UT001.1 - Document typography and readability
:PROPERTIES:
:CUSTOM_ID: ut-001-1-result
:END:

- Category :: User test.
- Definition :: [[file:spec.org::#ut-001-1][UT001.1 - Document typography and readability]].
- Criteria :: [[spec.org::#ac-001-4][AC001.4 - Markdown structure survives conversion]], [[spec.org::#ac-001-5][AC001.5 - Org information survives conversion]], [[spec.org::#ac-001-18][AC001.18 - Proportional text uses the appropriate Asap face]], [[spec.org::#ac-001-19][AC001.19 - Fixed-width text uses Iosevka Custom]], [[spec.org::#ac-001-43][AC001.43 - Application text meets contrast requirements]].
- Reviewer :: Taḋg or an explicitly named operator.
- Procedure :: *Inspect representative Markdown and Org* at wide and narrow window
  sizes, in light and dark modes. Include regular, italic, bold, code, tables,
  images, and =Taḋg ÁÉÍÓÚ áéíóú=. Use every browser environment in the
  qualification matrix and record exact versions and viewport sizes.
  Confirm the rendered font faces in the
  browser inspector, not just their CSS declarations. Inspect *inline code,
  code blocks, preformatted text, keyboard/sample text, and fixed-width Org
  metadata*; include regular, italic, bold, and bold italic examples. Verify
  equal-width character columns and the actual packaged Iosevka Custom face
  selected for each style, including Irish glyphs within code.
  Measure the application text colours against their backgrounds in both themes;
  record the lowest body and large-text contrast ratios.
- Expected :: *Text remains readable without clipping or missing glyphs*;
  headings, metadata, and code remain distinguishable. *Asap uses the appropriate
  face* for proportional text; *fixed-width text uses the matching Iosevka Custom
  face and aligned character columns*. *Contrast meets 4.5:1 for body text and
  3:1 for large text* across both themes.
- Result :: PENDING.
- Evidence :: *Not run*. Record the revision, environment, dated result, and named authority or execution owner. Include archive hash and cleanup for the packaging test.

** UT001.2 - Browser navigation and outline controls
:PROPERTIES:
:CUSTOM_ID: ut-001-2-result
:END:

- Category :: User test.
- Definition :: [[file:spec.org::#ut-001-2][UT001.2 - Browser navigation and outline controls]].
- Criteria :: [[spec.org::#ac-001-9][AC001.9 - Local references use the source directory]], [[spec.org::#ac-001-10][AC001.10 - Org IDs remain usable]], [[spec.org::#ac-001-11][AC001.11 - Reading works without JavaScript]], [[spec.org::#ac-001-21][AC001.21 - Same-page fragments stay on the preview]], [[spec.org::#ac-001-23][AC001.23 - Heading links use actual generated destinations]], [[spec.org::#ac-001-24][AC001.24 - Keyboard focus traversal remains available]], [[spec.org::#ac-001-25][AC001.25 - Fragment navigation reveals folded ancestors]], [[spec.org::#ac-001-26][AC001.26 - Printing includes every fold state]], [[spec.org::#ac-001-34][AC001.34 - Reading sessions retain their whole preview set]], [[spec.org::#ac-001-35][AC001.35 - Quick previews expire after their grace period]], [[spec.org::#ac-001-41][AC001.41 - Org outline state is deterministic]].
- Reviewer :: Taḋg or an explicitly named operator.
- Procedure :: *Navigate local links and fragments*, including targets with folded
  ancestors. Use controls with the keyboard, disable JavaScript, and inspect print
  preview from every fold state, including closed drawers. Use every browser
  environment in the qualification matrix and record exact versions. In reading mode, reload
  and follow generated pages before ending the session; in quick mode, note the
  declared expiry and try a deliberately delayed browser launch.
- Expected :: *Links reach their destinations*; normal focus traversal and visible
  focus remain available; *fragment navigation reveals hidden targets*. Reading
  works without JavaScript, and *printing includes all content*. *Reading-mode
  pages remain available until termination*. Quick mode's slow-browser race is
  reported as a documented limitation, never as proof that the browser loaded
  before expiry.
- Result :: PENDING.
- Evidence :: *Not run*. Record the revision, environment, dated result, and named authority or execution owner. Include archive hash and cleanup for the packaging test.

** UT001.4 - Installed previews across desktop platforms
:PROPERTIES:
:CUSTOM_ID: ut-001-4-result
:END:

- Category :: User test.
- Definition :: [[file:spec.org::#ut-001-4][UT001.4 - Installed previews across desktop platforms]].
- Criteria :: [[file:spec.org::#ac-001-45][AC001.45 - Each platform opens its system default browser]],
  [[file:spec.org::#ac-001-46][AC001.46 - WSL previews retain Windows-readable local references]].
- Reviewer :: Taḋg or an explicitly named operator.
- Procedure :: *Install into an OS-temporary prefix and invoke through a symlink
  from an unrelated directory* in each qualification environment, without
  installed Asap/Iosevka fonts or a checkout beside the executable. Confirm the
  OS default browser before invocation, then observe the actual application
  opened. In WSL, use separate fixture trees on the Linux filesystem and a
  mounted Windows drive; include Unicode/spaced paths, relative images, linked
  Markdown/Org, original-file links, and folded fragment targets. Keep WSLg
  available for one WSL2 run and confirm Windows still receives the handoff.
  Reload and navigate in reading mode, then end the session and inspect cleanup.
  Run the same typography, navigation, and passive-content procedures defined
  by the other user tests and record their results separately.
- Expected :: *The configured default browser displays the finished preview*
  on macOS and Linux; *the Windows default browser does so from WSL*. Local
  images and all supported links reach the intended content. Embedded fonts
  render without system installation. Original sources and permissions remain
  unchanged, generated output stays in the private temporary directory, and
  cleanup removes only that invocation's output. Process exit alone is not PASS.
- Result :: PENDING for macOS, Linux desktop, WSL1, and WSL2.
- Evidence :: *Not run*. Record revision, OS/CPU, browser identity/version, WSL
  version/distribution, Pandoc, paths, and dated human observations separately
  for each qualification environment. Cross-compilation and opener doubles are
  not browser evidence.

* One-off tests

** OT001.1 - Local Homebrew package validation
:PROPERTIES:
:CUSTOM_ID: ot-001-1-result
:END:

- Category :: Bounded one-off test.
- Definition :: [[file:spec.org::#ot-001-1][OT001.1 - Local Homebrew package validation]].
- Criteria :: [[spec.org::#ac-001-29][AC001.29 - Independent installation]] and [[spec.org::#ac-001-8][AC001.8 - Distribution licence notices]].
- Boundary :: *The actual Homebrew installer and built release archive* on the supported macOS/arm64 host, using only a local temporary tap.
- Procedure :: Build the candidate archive and checksum with =make release=. Prepare a temporary local tap from the generated formula and compare its recipe with the committed template. Use *the exact local archive and checksum*. Install, run help/version and one synthetic preview outside the checkout, then uninstall and remove the tap. Record the archive hash, recipe delta, Pandoc version, and actual commands.
- Expected :: *Homebrew declares/resolves Pandoc and installs a usable command* with packaged assets and notices. This validates local installation mechanics, not release hosting, published tap discovery, or older platforms.
- Bounds :: *One install and one uninstall*, no release publication, no private source data, no metered service, and no automatic retries. Stop after the first failure and retain diagnostics. Use the same htmlpreview formula class/name in an unoccupied temporary tap; stop if htmlpreview is already installed through Homebrew. Never replace an unrelated installed package. Allocate scratch with the OS temporary-directory API. Limit the operation to ten minutes.
- Execution owner :: *The operator runs the Homebrew steps*. The agent prepares the candidate and temporary recipe only; this test does not grant the agent permission to modify global package-manager state.
- Result :: PENDING.
- Evidence :: *Not run*. Record the revision, environment, dated result, and named authority or execution owner. Include archive hash and cleanup for the packaging test.
