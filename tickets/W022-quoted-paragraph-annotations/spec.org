* Synopsis
:PROPERTIES:
:CUSTOM_ID: summary
:END:
** Outcome
- Markdown quotations *remain annotatable* within numbered lists.
** Before
- Temporary references terminate lists and invalidate *whole chapter mappings*.
** After
- New references attach to the *selected paragraph end*, inside the quotation.
- Footnote definitions *remain at the document end*.
** Changes
- Goldmark paragraph spans replace after-quotation insertion candidates.
** Unchanged
- Heading, table, code and Org placement, guarded writes and existing notes remain unchanged.
** Edge cases
- Wrapped paragraphs, multiple quoted paragraphs, repeated notes and neighbouring code preserve their source structure.
** Decisions
- Sentence-level placement is *out of scope*; no Writeback integration is included.
** Next step
- Resolve required verification blockers, review the candidate, then perform user validation.

* Context
:PROPERTIES:
:CUSTOM_ID: context
:END:
** Problem and scope
A Markdown document containing numbered list items with indented quotations exposed
only its title and introduction as annotation targets. Temporary unindented
references split lists; rendered-structure pairing then rejected the chapter subtrees.
The emergency scope covers *paragraph-end references* in Markdown quotations and
restoration of surrounding annotation targets. It excludes sentence segmentation,
cell-level table annotations, service lifecycle changes and dependency upgrades.

* Edge Cases
- Paragraphs with multiple source lines use the *last text segment*, not an intermediate sentence.
- Quoted code, tables and definitions are not prose paragraphs. Parser classification and existing rendered proof prevent invented inline boundaries.
- Frontmatter and excluded note definitions retain the existing source scanner guards.

* Solution Design
:PROPERTIES:
:CUSTOM_ID: solution-design
:END:
Goldmark, already used for native Markdown rendering, supplies source spans for
paragraphs and tight-list text blocks inside blockquotes. The existing block
scanner admits these offsets only after its frontmatter, footnote and literal
exclusions. References use ordinary inline boundaries, shared by temporary proof
and guarded saves. The after-quotation insertion branch is retired for Markdown.
The DOM verifier and browser's nearest-paragraph targeting are unchanged.

A parser pass avoids reimplementing quotation/list nesting and excludes quoted
literal blocks. No dependency, endpoint, storage format or browser code is added.
The change is bounded by the existing source budget and renderer deadline.

** Security impact
Existing capability, origin, revision, source-root and atomic-write checks remain
in force. Temporary probe markers are never persisted. Dependency scanning remains
a delivery prerequisite; unrelated dependency upgrades require separate authority.
